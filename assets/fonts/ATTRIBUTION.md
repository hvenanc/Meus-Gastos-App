# Ícones dos bancos brasileiros

Autor: Matheus Cuba. Caminho original: `dist/Fonte-Bancos-Brasileiros.ttf`.

O mapa de caracteres segue `dist/icones-bancos-brasileiros.css` do mesmo commit.

Os logotipos e nomes dos bancos pertencem aos respectivos titulares.
A fonte é incorporada ao app para renderização offline via Expo Vector Icons,
sem CDN, redesenho de logotipos ou execução de código do repositório.

Atualmente, apenas Banco Original usa esta fonte, pois seu registro na nova
base não possui LogoUrl. Os demais logos e seus créditos estão em ../banks/.
